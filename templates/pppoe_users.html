Panduan Input Data Pelanggan PPPoE

📡 Server MikroTik

Pilih server MikroTik tempat akun PPPoE pelanggan akan dibuat. Pastikan server sudah terhubung (ping hijau di halaman Server).

🔐 Username & Password

Username dan password untuk login PPPoE di router pelanggan. Username harus unik dan tidak boleh ada spasi.

📅 Tanggal Bayar

Tanggal jatuh tempo tagihan setiap bulan (1–28).
Alur otomatis:
1. Setiap tgl X jam 07:00 → tagihan dibuat
2. Tgl X + grace period jam 10:00 → jika belum bayar, akun otomatis di-isolir di MikroTik
Grace period saat ini: {{ grace_period }} hari (ubah di Pengaturan → Billing)

🗓 Tanggal Mulai Berlangganan

Tanggal pemasangan. Tagihan pertama dihitung secara prorate (proporsional) dari tanggal ini hingga tgl bayar berikutnya.

🔧 Status Pemasangan

Belum Terpasang: akun dibuat di MikroTik tapi status masih menunggu teknisi.
Sudah Terpasang: akun langsung aktif.
