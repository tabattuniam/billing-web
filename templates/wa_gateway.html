📖 Cara Daftar Fonnte

  1. Buka fonnte.com → daftar akun
  2. Add Device → scan QR dengan HP WhatsApp
  3. Pilih paket & bayar (Rp 50rb/bln)
  4. Salin token dari menu Device (ikon 🔑)
  5. Paste token di form kiri → Simpan
  1. Buka wablas.com → daftar akun
  2. Pilih paket & bayar (ada trial 3 hari)
  3. Scan Device → scan QR dengan HP WhatsApp
  4. Buka menu API → Token
  5. Paste token di form kiri → Simpan
