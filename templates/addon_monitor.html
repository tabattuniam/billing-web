Matikan Bot Monitoring?

Bot akan berhenti mengirim notifikasi online/offline ke Telegram.

⚠️ Konfigurasi (token, chat ID) akan tetap tersimpan dan bisa diaktifkan kembali kapan saja.

Panduan Setup Bot Telegram

1

Buat Bot via @BotFather

  1. a. Buka Telegram, cari @BotFather dan klik Start
  2. b. Ketik perintah /newbot
  3. c. Masukkan nama bot (contoh: Monitor ISP Saya)
  4. d. Masukkan username bot — harus diakhiri _bot (contoh: monitor_isp_saya_bot)
  5. e. BotFather akan memberi Token Bot berformat:
7123456789:AAFxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Salin token ini dan tempel di kolom Token Bot Telegram di atas.

2

Buat Grup & Tambahkan Bot

  1. a. Buat grup Telegram baru (contoh: "Monitor PPPoE ISP")
  2. b. Tambahkan bot yang baru dibuat ke dalam grup tersebut
  3. c. Jadikan bot sebagai Admin grup agar bisa mengirim pesan
3

Dapatkan Group Chat ID

Ada dua cara mendapatkan Chat ID grup:

Cara A — via @userinfobot

  1. 1. Tambahkan @userinfobot ke grup
  2. 2. Ketik pesan apa saja di grup
  3. 3. Bot akan membalas dengan info termasuk Id: -1001234567890
  4. 4. Salin angka tersebut (termasuk tanda minus)

Cara B — via Telegram Web

  1. 1. Buka web.telegram.org dan masuk ke grup
  2. 2. Lihat URL di browser, contoh: #-1001234567890
  3. 3. Angka setelah # adalah Chat ID grup Anda

Chat ID grup selalu berupa angka negatif (diawali tanda minus). Jika positif, berarti itu ID personal/channel, bukan grup.

4

Isi Form & Test Kirim

  1. a. Tempel Token Bot dan Group Chat ID ke form konfigurasi
  2. b. Atur Grace Period — waktu tunggu sebelum kirim notifikasi offline (default 1 menit)
  3. c. Klik Simpan Konfigurasi lalu klik Kirim Test
  4. d. Jika berhasil, cek grup Telegram Anda — seharusnya ada pesan konfirmasi
