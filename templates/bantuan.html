🚀 Memulai

Setelah login, ikuti langkah awal berikut agar sistem berjalan optimal:

  1. Tambah Router MikroTik — masuk ke menu Server MikroTik, isi IP VPN, port API (default 8728), username, dan password router.
  2. Buat Paket — buat paket PPPoE atau Hotspot sesuai layanan yang ditawarkan (nama, kecepatan, harga, durasi).
  3. Hubungkan WhatsApp — masuk ke menu WA Gateway, scan QR untuk menghubungkan nomor WA notifikasi.
  4. Atur Profil & Slug — di menu Profil, set slug bisnis Anda (misal: jasa-net) untuk URL toko publik.
  5. Bagikan Link Toko — link publik Anda: billing.vpntunel.my.id/beli/[slug]

🖥️ Router MikroTik

Daftar semua router MikroTik yang terhubung ke sistem. Satu akun bisa mengelola banyak router sekaligus.

Cara menambah router:

  • Isi Nama (label bebas, misal: Server Utama)
  • Isi VPN IP — IP lokal/VPN router yang bisa dijangkau dari server ini
  • Isi API Port — default MikroTik adalah 8728
  • Isi Username & Password API MikroTik (buat user khusus dengan permission API di Winbox)
  • Isi Lokasi (opsional) sebagai keterangan
Tips: Pastikan port API MikroTik terbuka dan IP server billing masuk ke whitelist firewall MikroTik. Gunakan tombol Ping untuk mengecek koneksi.

📡 PPPoE (Point-to-Point Protocol over Ethernet)

🌐 Apa itu PPPoE?

PPPoE adalah teknologi koneksi internet untuk pelanggan rumahan/dedicated. Pelanggan menggunakan username & password untuk dial koneksi ke router ISP. Cocok untuk layanan internet bulanan dengan tagihan berlangganan.

Contoh use case: ISP rumahan, RT/RW Net dengan pelanggan tetap, layanan dedicated internet.

1️⃣ Paket PPPoE

Buat paket layanan PPPoE dengan menentukan:

  • Nama Paket — misal: "10 Mbps Unlimited", "20 Mbps Premium"
  • Kecepatan Upload — rate limit upload (misal: 10M = 10 Mbps)
  • Kecepatan Download — rate limit download (misal: 10M = 10 Mbps)
  • Harga Bulanan — harga berlangganan per bulan
  • Profile MikroTik — profile PPPoE yang sudah dibuat di router
💡 Tips: Gunakan tombol Import dari MikroTik untuk mengambil profile PPPoE yang sudah ada di router. Lebih cepat daripada input manual.

2️⃣ Tambah Pelanggan PPPoE

Daftarkan pelanggan baru ke sistem.

Data yang perlu diisi:

  • Nama Pelanggan — nama lengkap pelanggan
  • Username PPPoE — username untuk dial koneksi (unik, tidak boleh sama)
  • Password PPPoE — password untuk dial koneksi
  • Server MikroTik — router yang akan digunakan
  • Paket — paket layanan yang dipilih
  • Nomor WA — nomor WhatsApp pelanggan (format: 628xxx, tanpa +/spasi) untuk reminder tagihan
  • Alamat — alamat pelanggan (opsional)
  • Tanggal Bayar — tanggal jatuh tempo rutin tiap bulan (misal: 1, 5, 10, dst)
✅ Setelah simpan: Pelanggan otomatis berstatus Aktif. Jangan lupa klik tombol Push ke MikroTik untuk membuat secret PPPoE di router.

3️⃣ Push ke MikroTik

Agar pelanggan bisa konek, data PPPoE harus di-push ke router.

  • Klik tombol Push ke MikroTik di halaman pelanggan
  • Sistem akan membuat PPP Secret di router dengan username, password, dan profile yang sudah ditentukan
  • Jika berhasil, badge MikroTik ✓ akan muncul

4️⃣ Status Pelanggan

Aktif — Pelanggan bisa konek, tagihan berjalan normal
Suspend — Pelanggan tidak bisa konek (secret disabled di MikroTik)
— Ikon hijau berkedip = pelanggan sedang online

5️⃣ Tagihan PPPoE

Sistem membuat tagihan otomatis setiap bulan sesuai tanggal bayar pelanggan.

Fitur Tagihan:

  • Generate Tagihan Manual — buat tagihan untuk bulan tertentu jika belum ada
  • Kirim Link Bayar — kirim link pembayaran online (QRIS/transfer) via WA ke pelanggan
  • Tandai Lunas — tandai tagihan yang sudah dibayar secara manual (cash/transfer langsung)
  • Reminder — kirim WA pengingat massal ke semua pelanggan yang belum bayar
  • Filter — filter tagihan berdasarkan bulan, status (unpaid/paid/overdue)

6️⃣ Suspend Otomatis

⚠️ Sistem Suspend Otomatis

Setiap hari jam 03:00 WIB, sistem akan:

  1. Cek tagihan yang sudah melewati jatuh tempo (status overdue)
  2. Suspend pelanggan yang tagihan overdue (disabled secret di MikroTik)
  3. Pelanggan tidak bisa konek sampai tagihan dibayar

Reaktivasi: Setelah tagihan ditandai lunas, pelanggan otomatis diaktifkan kembali.

7️⃣ Tagihan Prorate (Tagihan Pertama)

Tagihan pertama pelanggan dihitung proporsional dari tanggal pasang sampai tanggal bayar rutin. Tagihan bulan berikutnya dan seterusnya selalu full price.

📐 Rumus Prorate

Harga ÷ 30 × Jumlah Hari

Dibulatkan ke kelipatan Rp 500 terdekat

📋 Tiga Skenario Tagihan Pertama

① Pasang di tengah bulan (prorate)

Pasang tgl 1 Juli, bayar rutin tgl 6, harga Rp 150.000

1 Juli → 6 Juli = 5 hari

150.000 ÷ 30 × 5 = Rp 25.000

⚡ Tagihan: 6 Juli → lalu tgl 6 Agustus full price Rp 150.000

② Pasang tepat di hari tgl bayar (skip bulan ini)

Pasang tgl 1 Juli, bayar rutin tgl 1

1 Juli → 1 Juli = 0 hari → tidak ada yang perlu dibayar bulan ini

Tagihan pertama baru muncul bulan depan (full price)

⚡ Tagihan: 1 Agustus Rp 150.000 (langsung full price)

③ Prorate lebih besar (pasang jauh sebelum tgl bayar)

Pasang tgl 20 Juni, bayar rutin tgl 1, harga Rp 200.000

20 Juni → 1 Juli = 11 hari

200.000 ÷ 30 × 11 = Rp 73.333 → Rp 73.500

⚡ Tagihan: 1 Juli → lalu tgl 1 Agustus full price Rp 200.000
💡 Kolom "⚡ Tagihan" di tabel pelanggan menunjukkan kapan pertama kali tagihan akan di-generate otomatis untuk pelanggan tersebut. Berguna untuk verifikasi saat input data pelanggan baru.

Prorate tidak berlaku jika selisih ≥ 30 hari (dianggap full price).

8️⃣ Grace Period (Toleransi Keterlambatan)

Jumlah hari tambahan setelah tanggal jatuh tempo sebelum pelanggan masuk status overdue dan otomatis di-suspend.

Default grace period 10 hari

Contoh:

Tgl bayar 1, grace period 10 hari

→ Jatuh tempo efektif: tgl 11

→ Reminder WA dikirim H-3, H-1, H+1 dari tgl 11

→ Suspend otomatis tgl 12 jam 10:00 jika belum bayar

Nilai grace period dapat diubah di halaman Profil → Grace Period (min 1, maks 30 hari).

9️⃣ Import CSV (Bulk Add)

Tambah banyak pelanggan sekaligus dengan file CSV.

Format CSV:

nama,username,password,paket_id,telepon,alamat,tgl_bayar
Budi,budi123,pass123,1,6281234567890,Jl. Merdeka No.1,1
Ani,ani456,pass456,2,6289876543210,Jl. Sudirman No.5,5

Download template CSV dari halaman Pelanggan PPPoE.

📚 Workflow Lengkap PPPoE

  1. Buat Paket PPPoE (atau import dari MikroTik)
  2. Tambah Pelanggan dengan data lengkap (nama, username, password, nomor WA, tgl bayar)
  3. Push ke MikroTik agar pelanggan bisa konek
  4. Pelanggan dial PPPoE dengan username/password yang diberikan
  5. Sistem generate tagihan otomatis setiap bulan sesuai tgl bayar (tagihan pertama dihitung prorate)
  6. Sistem kirim reminder WA H-3, H-1, H-0, H+1 dari jatuh tempo (jam 08:00 WIB)
  7. Jika pelanggan bayar, tandai lunas (atau otomatis via payment gateway)
  8. Jika tidak bayar melewati grace period (default 10 hari setelah tgl bayar), suspend otomatis jam 10:00 WIB

🔔 Reminder Tagihan Otomatis

Cara Kerja Reminder

Sistem akan mengirim reminder WA otomatis ke pelanggan PPPoE sesuai jadwal berdasarkan tanggal jatuh tempo (bukan tanggal bayar).

📅 Perhitungan Jatuh Tempo

Tanggal Bayar Pelanggan: 1 Juli
+ Grace Period: 10 hari
= Jatuh Tempo: 11 Juli

📨 Jadwal Pengiriman Reminder

🔔

H-3 (3 hari sebelum jatuh tempo)

Contoh: Jatuh tempo 11 Juli → reminder dikirim 8 Juli

"Tagihan jatuh tempo 3 hari lagi (11 Jul)"

⚠️

H-1 (1 hari sebelum jatuh tempo)

Contoh: Jatuh tempo 11 Juli → reminder dikirim 10 Juli

"Tagihan jatuh tempo besok (11 Jul)"

🚨

H-0 (hari jatuh tempo)

Contoh: Jatuh tempo 11 Juli → reminder dikirim 11 Juli

"Tagihan jatuh tempo hari ini (11 Jul)"

❗

H+1 (1 hari setelah jatuh tempo)

Contoh: Jatuh tempo 11 Juli → reminder dikirim 12 Juli

"Tagihan sudah melewati jatuh tempo (sejak 11 Jul)"

⏰ Waktu Eksekusi

  • Reminder otomatis berjalan setiap hari jam 08:00 WIB
  • Sistem akan cek semua pelanggan yang jatuh temponya H-3, H-1, H-0, atau H+1 hari itu
  • WA reminder dikirim otomatis beserta link pembayaran online
💡 Tips: Pastikan nomor WA pelanggan sudah terisi di data pelanggan agar reminder bisa terkirim. Pelanggan yang tidak punya nomor WA akan di-skip.

🎟️ Hotspot Voucher

📦 Apa itu Hotspot Voucher?

Voucher hotspot adalah kode akses internet sementara yang bisa dijual kepada pelanggan. Setiap voucher punya username & password unik, durasi (waktu), dan kecepatan internet yang sudah ditentukan.

Contoh use case: Warnet, cafe, hotel, RT/RW Net yang menjual paket internet harian/mingguan ke pelanggan.

1️⃣ Paket Hotspot

Buat paket voucher dengan menentukan:

  • Nama Paket — misal: "1 Hari 10 Mbps", "1 Minggu Unlimited"
  • Durasi/Validity — berapa lama voucher berlaku (1d = 1 hari, 7d = 7 hari, 30d = 1 bulan)
  • Kecepatan Upload/Download — rate limit untuk paket ini
  • Harga — harga jual per voucher (untuk agen & halaman toko publik)
  • Profile MikroTik — profile hotspot yang sudah dibuat di router
💡 Tips: Gunakan tombol Import dari MikroTik untuk mengambil profile hotspot yang sudah ada di router, jadi tidak perlu input manual.

2️⃣ Generate Voucher

Setelah paket dibuat, Anda bisa generate voucher dalam jumlah banyak sekaligus.

Langkah Generate:

  1. Pilih Server MikroTik yang akan digunakan
  2. Pilih Paket Hotspot (misal: "1 Hari 10 Mbps")
  3. Tentukan Jumlah Voucher yang mau di-generate (maks 500 per batch)
  4. Isi Comment/Batch sebagai label kelompok voucher (misal: "RT 01", "Promo Juli", "Warnet A")
  5. Centang Push ke MikroTik agar voucher langsung dibuat di router (recommended)
  6. Klik Generate
✅ Hasil: Sistem akan membuat voucher dengan username & password random, lalu push ke MikroTik. Voucher siap dijual!

3️⃣ Status & Badge Voucher

Setiap voucher punya status yang bisa dilihat dari badge warna:

Tersedia — Voucher belum dipakai, bisa dijual
Dipakai — Voucher sudah dipakai pelanggan, sedang aktif
Expired — Voucher sudah habis masa berlakunya
MikroTik ✓ — Voucher sudah ada di router
Belum push — Voucher belum di-push ke router

4️⃣ Push Ulang ke MikroTik

Jika ada voucher yang gagal push (badge "Belum push"), Anda bisa push ulang:

  • Pilih Server di filter
  • Klik tombol Push ke MikroTik (ada di atas tabel voucher)
  • Sistem akan push semua voucher yang belum masuk ke router

5️⃣ Cetak Voucher

Voucher yang sudah di-generate bisa dicetak untuk dijual ke pelanggan.

Cara Cetak:

  1. Filter voucher berdasarkan Comment/Batch (misal: "RT 01")
  2. Klik tombol Cetak
  3. Halaman print-friendly akan terbuka dengan desain voucher + QR code
  4. Tekan Ctrl+P (Windows/Linux) atau Cmd+P (Mac) untuk print
💡 Tips: QR code bisa di-scan pelanggan untuk langsung redirect ke halaman login hotspot. Lebih praktis daripada ketik username/password manual.

6️⃣ Filter Voucher

Gunakan filter untuk mencari voucher tertentu:

  • Server — filter berdasarkan router MikroTik
  • Paket — filter berdasarkan paket hotspot
  • Status — Tersedia / Dipakai / Expired
  • Comment/Batch — filter berdasarkan label kelompok
  • Cari — cari berdasarkan username voucher

7️⃣ Hapus Voucher

Voucher yang sudah tidak dipakai bisa dihapus untuk menghemat database & router.

⚠️ Hapus Tersedia (Bulk Delete)

Menghapus semua voucher tersedia di server yang dipilih. Voucher juga dihapus dari MikroTik.

Gunakan dengan hati-hati! Voucher yang dihapus tidak bisa dikembalikan.

🗑️ Hapus per Comment/Batch

Menghapus satu batch voucher berdasarkan label comment. Lebih aman karena hanya menghapus kelompok tertentu.

📌 Catatan: Voucher dengan status Dipakai atau Expired tidak bisa dihapus untuk menjaga history pemakaian.

📚 Workflow Lengkap Hotspot Voucher

  1. Buat Paket Hotspot (atau import dari MikroTik)
  2. Generate Voucher sesuai kebutuhan (dengan comment/batch)
  3. Cetak Voucher hasil generate
  4. Jual voucher ke pelanggan
  5. Pelanggan login hotspot dengan username/password voucher
  6. Setelah masa berlaku habis, voucher otomatis expired
  7. Hapus voucher expired secara berkala untuk menjaga kebersihan database

📅 Hotspot Bulanan Addon +Rp 20.000/bulan

📅 Apa itu Hotspot Bulanan?

Fitur untuk mengelola pelanggan hotspot dengan sistem berlangganan bulanan. Berbeda dengan voucher (kode acak sekali pakai), hotspot bulanan punya data pelanggan terdaftar, tagihan otomatis setiap bulan, dan reminder WA.

Aspek Voucher Bulanan

Tagihan otomatis❌✅
Reminder WA❌✅
Cocok untukWarung, cafe, tamuPelanggan tetap RT/RW

Cara Mengaktifkan

  1. Buka halaman Profil
  2. Scroll ke bagian Addon: Hotspot Bulanan
  3. Aktifkan toggle — fitur langsung tersedia di menu sidebar
  4. Biaya Rp 20.000/bulan akan ditambahkan ke tagihan SaaS bulan berikutnya
⚠️ Catatan Biaya: Biaya Rp 20.000 dihitung per bulan kalender. Jika diaktifkan di tengah bulan, tagihan tetap berlaku penuh bulan berikutnya. Nonaktifkan sebelum tanggal 1 jika tidak ingin ditagih.

👥 Sistem Agen (Reseller)

🤝 Apa itu Sistem Agen?

Agen adalah reseller yang bisa generate dan menjual voucher hotspot atas nama ISP. Agen punya saldo sendiri yang dipotong saat generate voucher, lalu agen jual voucher ke pelanggan akhir dengan margin keuntungan.

Contoh use case: ISP punya agen di berbagai wilayah/RT untuk distribusi voucher. Agen topup saldo, generate voucher sendiri, cetak, dan jual ke pelanggan.

1️⃣ Tambah Agen (Sisi ISP)

ISP menambahkan akun agen baru di menu Agen.

Data yang perlu diisi:

  • Nama Agen — nama lengkap/toko agen
  • Username — username untuk login agen (unik)
  • Password — password login agen
  • Nomor WA — nomor WhatsApp agen untuk notifikasi
  • Status — Aktif/Nonaktif (agen nonaktif tidak bisa login)

2️⃣ Login Agen

Setelah akun dibuat, agen login di:

https://billing.vpntunel.my.id/beli/[slug-isp]/login

Ganti [slug-isp] dengan slug bisnis ISP (bisa dilihat di menu Profil).

3️⃣ Topup Saldo Agen

Agen perlu topup saldo sebelum bisa generate voucher.

Cara topup:

  • Via Panel Agen: Agen bisa topup sendiri via QRIS/transfer dari panel mereka
  • Via ISP (Manual): ISP bisa tambah/kurangi saldo agen di menu Agen → Detail → Tambah/Kurangi Saldo Manual

4️⃣ Generate Voucher (Sisi Agen)

Setelah punya saldo, agen bisa generate voucher dari panel mereka.

Langkah generate:

  1. Pilih Paket Hotspot yang tersedia
  2. Pilih Server (jika ISP punya banyak router)
  3. Tentukan Jumlah Voucher
  4. Klik Generate
  5. Saldo agen dipotong sesuai: harga_paket × jumlah
✅ Hasil: Voucher masuk ke database dengan label comment otomatis (username agen). Agen bisa cetak voucher untuk dijual.

5️⃣ Cetak Voucher Agen

Agen bisa cetak voucher hasil generate dari panel mereka.

  • Klik Riwayat Generate di panel agen
  • Pilih batch voucher yang mau dicetak
  • Klik Cetak untuk print voucher dengan QR code

6️⃣ Monitoring Agen (Sisi ISP)

ISP bisa monitor aktivitas agen:

  • Saldo Agen — lihat sisa saldo tiap agen
  • Riwayat Generate — lihat voucher yang sudah di-generate agen
  • Riwayat Topup — lihat history topup saldo agen
  • Nonaktifkan Agen — agen yang dinonaktifkan tidak bisa login & generate
⚠️ Perhatian: Agen yang dinonaktifkan tidak bisa login. Saldo agen tetap tersimpan dan bisa diaktifkan kembali kapan saja.

📚 Workflow Lengkap Sistem Agen

  1. ISP tambah akun agen (nama, username, password)
  2. Agen login di billing.../beli/[slug]/login
  3. Agen topup saldo via panel atau minta ISP isi manual
  4. Agen generate voucher sesuai kebutuhan (saldo dipotong otomatis)
  5. Agen cetak voucher dari panel
  6. Agen jual voucher ke pelanggan akhir dengan harga + margin
  7. Pelanggan pakai voucher untuk login hotspot
  8. ISP bisa monitor aktivitas & saldo agen kapan saja

💬 WhatsApp Gateway

📱 Apa itu WhatsApp Gateway?

WhatsApp Gateway memungkinkan sistem mengirim notifikasi otomatis ke pelanggan via WhatsApp, seperti:

  • Reminder tagihan (H-3, H-1, H-0, H+1)
  • Link pembayaran online (QRIS/transfer)
  • Konfirmasi pembayaran diterima
  • Notifikasi aktivasi/suspend akun

1️⃣ Cara Menghubungkan WhatsApp

Langkah setup:

  1. Buka menu WA Gateway di sidebar
  2. Klik tombol Scan QR Code
  3. QR code akan muncul di layar
  4. Buka WhatsApp di HP Anda
  5. Tap ⋮ (titik tiga) → Perangkat Tertaut
  6. Tap Tautkan Perangkat
  7. Scan QR code yang muncul di layar billing
  8. Tunggu sampai status berubah jadi Connected
✅ Berhasil: Status akan berubah jadi "Connected" dan nomor WA Anda akan tampil. Sistem siap kirim notifikasi!

2️⃣ Status Koneksi

Connected — WA terhubung, sistem bisa kirim notifikasi
Disconnected — WA terputus, perlu scan QR ulang
Not Setup — Belum pernah di-setup, perlu scan QR

3️⃣ Test Kirim Pesan

Setelah terhubung, test apakah WA bisa kirim pesan:

  • Di halaman WA Gateway, masukkan nomor tujuan (format: 628xxx, tanpa +)
  • Ketik pesan test
  • Klik Kirim Test
  • Cek HP tujuan, pastikan pesan masuk

4️⃣ Notifikasi Otomatis yang Dikirim

📅 Reminder Tagihan

Dikirim otomatis H-3, H-1, H-0, H+1 dari jatuh tempo (jam 08:00 WIB) ke pelanggan PPPoE yang belum bayar.

✅ Konfirmasi Pembayaran

Dikirim otomatis setelah pelanggan bayar via payment gateway (QRIS/transfer).

🎉 Aktivasi Akun

Dikirim saat pelanggan baru didaftarkan (berisi username, password, tanggal bayar).

⚠️ Suspend/Reaktivasi

Dikirim saat akun pelanggan di-suspend atau diaktifkan kembali.

5️⃣ Disconnect/Logout WA

Jika ingin ganti nomor WA atau troubleshoot koneksi:

  • Klik tombol Disconnect di halaman WA Gateway
  • Refresh halaman (F5)
  • Scan QR code ulang dengan nomor WA yang baru

6️⃣ Template Pesan WA

Di menu Template WA, Anda bisa mengubah teks notifikasi yang dikirim ke pelanggan. Variabel yang tersedia:

{% set vars = [ ('{nama}','Nama pelanggan'),('{jumlah}','Nominal tagihan'), ('{bulan}','Bulan tagihan'),('{link}','Link pembayaran'), ('{kode}','Kode voucher'),('{durasi}','Durasi paket'), ('{paket}','Nama paket'),('{expired}','Tanggal jatuh tempo') ] %} {% for var, desc in vars %}
{{ var }} {{ desc }}
{% endfor %}
⚠️ Penting: Jangan logout WA di HP saat sistem masih terhubung, karena akan memutus koneksi gateway. Gunakan tombol Disconnect di panel billing terlebih dahulu.
🚫 Jika WA Sering Terputus:
  • Pastikan HP tidak mati/kehabisan baterai
  • Pastikan HP tetap terhubung internet (WiFi/data seluler)
  • Jangan logout WA di HP
  • Jangan hapus chat/perangkat tertaut di HP
  • Gunakan nomor WA khusus untuk gateway (bukan WA pribadi yang sering dipakai)

🤖 Bot Monitoring Telegram Add-on

📡 Apa itu Bot Monitoring Telegram?

Add-on yang mengirim notifikasi otomatis ke grup Telegram Anda setiap kali pelanggan PPPoE online atau offline. Bot juga dapat menjawab perintah langsung dari grup untuk cek status pelanggan secara real-time.

📬 Notifikasi Otomatis

🔴 Pelanggan OFFLINE

📡 Server: Server Utama
⏱ Offline sejak: 5 menit

Dikirim setelah grace period berlalu (default 1 menit setelah disconnect).

🟢 Pelanggan ONLINE

🟢 ONLINE — budi123 (Budi Santoso)
📡 Server: Server Utama

Dikirim sesaat setelah pelanggan berhasil konek.

Notifikasi menampilkan username PPPoE + nama pelanggan (jika terdaftar di sistem).

Contoh: /cek budi123

📡 Server: Server Utama
🕐 Terakhir berubah: 12 menit lalu

Notif Offline 🔴 — aktifkan/nonaktifkan notifikasi saat pelanggan disconnect.

Notif Online 🟢 — aktifkan/nonaktifkan notifikasi saat pelanggan konek.

📌 Catatan: Monitoring berjalan setiap 30 detik. Perintah bot diproses setiap 15 detik. Ada kemungkinan delay maksimal 30-45 detik dari perubahan status sampai notifikasi masuk.

❓ FAQ (Pertanyaan Umum)

Q: Kenapa pelanggan tidak dapat reminder WA?

A: Cek hal berikut:

  • Nomor WA pelanggan sudah terisi dengan format 628xxx (tanpa +, tanpa spasi)
  • WA Gateway sudah terhubung dan status Connected
  • Tagihan pelanggan statusnya unpaid (bukan paid)
  • Belum sampai H-3 dari jatuh tempo (cek perhitungan di bagian Reminder Tagihan)

Q: Bagaimana cara ubah tanggal bayar pelanggan?

A: Masuk ke menu Pelanggan PPPoE → klik tombol Edit pada pelanggan yang ingin diubah → ubah field Tgl Bayar → Simpan. Tagihan bulan ini yang masih unpaid akan dihapus dan di-generate ulang dengan tgl bayar baru. Jatuh tempo otomatis menyesuaikan.

Q: Kenapa pelanggan baru pasang tgl 1 tapi tagihan pertama muncul bulan depan?

A: Karena pelanggan pasang di hari yang sama dengan Tgl Bayar-nya. Contoh: pasang 1 Juli, tgl bayar = 1 → selisih hari = 0 → tidak ada yang ditagih bulan ini, tagihan pertama muncul 1 Agustus (full price). Ini adalah perilaku normal — pelanggan baru mulai siklus penuh dari bulan depan. Kolom ⚡ Tagihan di tabel pelanggan menunjukkan kapan tagihan pertama akan muncul.

Q: Apa itu kolom "⚡ Tagihan" di tabel pelanggan?

A: Kolom tersebut menampilkan tanggal pertama kali tagihan akan di-generate untuk pelanggan bersangkutan, dihitung dari tanggal pasang dan tanggal bayar rutinnya. Berguna untuk mengecek apakah input data pelanggan baru sudah benar sebelum tagihan pertama muncul.

Q: Apa bedanya suspend manual vs otomatis?

A: Suspend manual dilakukan oleh ISP dengan klik tombol suspend. Suspend otomatis dilakukan sistem setiap hari jam 03:00 WIB untuk pelanggan yang tagihan statusnya overdue (melewati jatuh tempo dan belum bayar).

Q: Voucher yang sudah di-generate bisa dihapus?

A: Bisa. Gunakan tombol Hapus Tersedia untuk hapus semua voucher dengan status Tersedia di server tertentu, atau Hapus per Comment untuk hapus satu batch voucher. Voucher yang sudah dipakai tidak bisa dihapus.

Q: Pelanggan bayar manual (cash/transfer), bagaimana tandai lunas?

A: Masuk ke menu Tagihan PPPoE → pilih bulan tagihan → klik tombol Tandai Lunas pada tagihan yang bersangkutan → isi metode bayar dan keterangan → Simpan. Pelanggan otomatis diaktifkan kembali jika sebelumnya di-suspend.

Q: Agen generate voucher tapi tidak muncul di list voucher ISP?

A: Voucher yang di-generate agen masuk ke sistem dan bisa dilihat di menu Hotspot Voucher. Filter berdasarkan Comment atau Server untuk melihat voucher hasil generate agen.

Q: Bagaimana cara menambah saldo agen?

A: Masuk ke menu Agen → klik nama agen → di halaman detail, ada form Tambah/Kurangi Saldo Manual. Isi nominal dan keterangan, lalu simpan. Saldo agen akan terupdate otomatis.

Q: Router MikroTik tidak bisa terhubung (status merah)?

A: Cek troubleshooting di bagian Troubleshooting di bawah untuk panduan lengkap koneksi MikroTik.

🛠️ Troubleshooting

🖥️ Router MikroTik Tidak Terhubung

Langkah pengecekan:

  1. Pastikan API MikroTik aktif: Winbox → IP → Services → pastikan service api atau api-ssl enabled di port 8728
  2. Cek Firewall MikroTik: pastikan IP server billing (IP_SERVER_BILLING) diizinkan akses ke port 8728
  3. User API harus punya permission: Winbox → System → Users → pastikan user yang dipakai punya group full atau minimal akses api, read, write
  4. Test koneksi manual: dari server billing, coba ping ke IP VPN router: ping [IP_VPN_ROUTER]
  5. Cek username/password: pastikan tidak ada typo di form tambah server

💬 WhatsApp Gateway Terputus (QR Expired)

Jika QR code expired atau WA terputus:

  1. Buka menu WA Gateway
  2. Klik tombol Disconnect atau Logout
  3. Refresh halaman (F5)
  4. Klik Scan QR lagi
  5. Buka WA di HP → Perangkat Tertaut → Tautkan Perangkat → scan QR baru

Catatan: Jangan logout WA di HP saat sistem masih terhubung, karena akan memutus koneksi gateway.

📡 Pelanggan PPPoE Tidak Bisa Konek

Cek urut dari atas:

  1. Status pelanggan: pastikan status Aktif di sistem billing (ikon hijau)
  2. Secret MikroTik: cek di Winbox → PPP → Secrets → pastikan username pelanggan ada dan tidak disabled
  3. Profile PPPoE: pastikan profile pelanggan sudah dibuat di MikroTik dan rate limit sudah sesuai
  4. Push ulang: jika belum, klik tombol Push ke MikroTik di halaman pelanggan
  5. Cek dari sisi pelanggan: pastikan username & password yang dimasukkan di dial PPPoE benar

🎟️ Voucher Hotspot Tidak Valid (Invalid Username/Password)

Kemungkinan penyebab:

  • Voucher belum di-push ke MikroTik: di halaman voucher, filter server lalu klik tombol Push ke MikroTik
  • User hotspot terhapus di MikroTik: cek Winbox → IP → Hotspot → Users → pastikan username voucher ada
  • Profile hotspot tidak ada: pastikan profile yang dipakai voucher sudah dibuat di MikroTik dengan rate limit yang sesuai
  • Voucher expired: cek kolom Expired di list voucher, voucher yang sudah expired tidak bisa dipakai lagi

💰 Pembayaran QRIS/Transfer Tidak Masuk

Jika pelanggan sudah bayar tapi status tagihan masih unpaid:

  1. Cek menu Transaksi → lihat status pembayaran (pending/success/failed)
  2. Jika status pending lebih dari 15 menit, kemungkinan webhook payment gateway gagal
  3. Hubungi support payment gateway (Mayar/Midtrans/Duitku) untuk cek status transaksi
  4. Jika sudah confirmed pembayaran valid, tandai tagihan Lunas Manual di menu Tagihan PPPoE

🔐 Lupa Password Login ISP

Hubungi administrator VPNTunel via WhatsApp/Telegram untuk reset password. Siapkan data verifikasi (username, nomor WA yang terdaftar).

⚠️ Masalah Lain: Jika masalah yang Anda hadapi tidak tercakup di atas, hubungi support VPNTunel dengan menyertakan screenshot error atau deskripsi lengkap masalahnya.
