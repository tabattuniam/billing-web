🚀 Memulai

Setelah login, ikuti langkah awal berikut agar sistem berjalan optimal:

  1. Tambah Router MikroTik — masuk ke menu Server MikroTik, isi IP VPN, port API (default 8728), username, dan password router.
  2. Buat Paket — buat paket PPPoE atau Hotspot sesuai layanan yang ditawarkan (nama, kecepatan, harga, durasi).
  3. Hubungkan WhatsApp — masuk ke menu WA Gateway, scan QR untuk menghubungkan nomor WA notifikasi.
  4. Atur Profil & Slug — di menu Profil, set slug bisnis Anda (misal: jasa-net) untuk URL toko publik.
  5. Bagikan Link Toko — link publik Anda: billing.vpntunel.my.id/beli/[slug]

🖥️ Router MikroTik

Daftar semua router MikroTik yang terhubung ke sistem. Satu akun bisa mengelola banyak router sekaligus.

Cara menambah router:

  • Isi Nama (label bebas, misal: Server Utama)
  • Isi VPN IP — IP lokal/VPN router yang bisa dijangkau dari server ini
  • Isi API Port — default MikroTik adalah 8728
  • Isi Username & Password API MikroTik (buat user khusus dengan permission API di Winbox)
  • Isi Lokasi (opsional) sebagai keterangan
Tips: Pastikan port API MikroTik terbuka dan IP server billing masuk ke whitelist firewall MikroTik. Gunakan tombol Ping untuk mengecek koneksi.

📡 PPPoE

Paket PPPoE

Buat paket layanan PPPoE (nama, kecepatan upload/download, harga bulanan). Paket bisa diimpor langsung dari profile MikroTik yang sudah ada.

  • Klik Import dari MikroTik untuk mengambil daftar profile PPPoE dari router
  • Paket yang dibuat di sini digunakan saat mendaftarkan pelanggan baru

Pelanggan PPPoE

Kelola semua pelanggan PPPoE: tambah, edit, suspend, aktifkan, dan push ke MikroTik.

  • Tambah Pelanggan — isi nama, username, password PPPoE, pilih paket & server, isi nomor WA untuk notifikasi tagihan
  • Push ke MikroTik — membuat secret PPPoE di router secara otomatis
  • Status Online — ikon hijau menandakan pelanggan sedang terkoneksi
  • Import CSV — impor banyak pelanggan sekaligus lewat file CSV
  • Tgl Bayar — tanggal jatuh tempo tiap bulan; sistem akan membuat tagihan otomatis

Tagihan PPPoE

Sistem membuat tagihan otomatis setiap bulan. Anda juga bisa generate manual.

  • Generate Tagihan — buat tagihan untuk bulan tertentu
  • Kirim Link Bayar — kirim link QRIS/transfer ke WA pelanggan
  • Tandai Lunas — tandai tagihan yang sudah dibayar manual
  • Reminder — kirim WA pengingat ke semua pelanggan yang belum bayar
  • Jika tidak bayar dan melewati jatuh tempo, pelanggan akan otomatis di-suspend (PPPoE secret dinonaktifkan)
Catatan: Suspend otomatis berjalan setiap hari pukul 03.00. Setelah pelanggan bayar dan tagihan ditandai lunas, PPPoE akan otomatis diaktifkan kembali.

🎟️ Hotspot Voucher

Paket Hotspot

Buat paket voucher (nama, durasi, kecepatan, harga). Bisa diimpor dari profile Hotspot MikroTik yang ada.

Generate Voucher

  • Pilih Server dan Paket, tentukan jumlah voucher (maks 500 per batch)
  • Isi Comment/Batch sebagai label kelompok (misal: RT 01, Promo Juli)
  • Centang Push ke MikroTik untuk langsung membuat user hotspot di router
  • Kolom Tgl Generate menunjukkan kapan voucher dibuat
  • Badge MikroTik ✓ (hijau) = sudah ada di router · Belum push (oranye) = belum

Push Ulang ke MikroTik

Jika ada voucher yang gagal push, gunakan tombol Push ke MikroTik di filter (setelah memilih server) untuk push ulang semua yang belum masuk.

Cetak Voucher

Tombol Cetak membuka halaman print-friendly dengan QR code tiap voucher, siap dicetak dan dijual ke pelanggan.

Filter & Hapus

  • Filter berdasarkan Server, Paket, Status (Tersedia/Dipakai/Expired), atau Comment
  • Hapus Tersedia — hapus semua voucher tersedia di server yang dipilih (juga dihapus dari MikroTik)
  • Hapus per Comment — hapus satu batch voucher berdasarkan label comment

👥 Sistem Agen

Agen adalah reseller yang bisa generate dan menjual voucher hotspot atas nama ISP. Setiap agen punya saldo yang dipotong saat generate voucher.

Alur Agen:

  1. ISP tambah akun agen di menu Agen (nama, username, password, nomor WA)
  2. Agen login di billing.vpntunel.my.id/beli/[slug]/login
  3. Agen topup saldo via QRIS/transfer di panel mereka
  4. Agen generate voucher — saldo dipotong sesuai harga paket × jumlah
  5. Agen cetak dan jual voucher ke pelanggan akhir

Panel Agen

  • Lihat saldo & riwayat generate
  • Pilih paket & server, tentukan jumlah, generate voucher
  • Cetak voucher hasil generate (per batch/comment)
  • Topup saldo lewat payment gateway yang tersedia
Perhatian: Agen yang dinonaktifkan tidak bisa login. Saldo agen bisa diatur manual oleh ISP di menu Agen → Detail.

💬 WhatsApp Gateway

Sistem menggunakan WA pribadi Anda untuk mengirim notifikasi tagihan, link bayar, dan konfirmasi pembayaran ke pelanggan.

Cara menghubungkan WA:

  1. Buka menu WA Gateway
  2. Klik tombol Hubungkan / Scan QR
  3. Buka WhatsApp di HP → Perangkat Tertaut → Tautkan Perangkat
  4. Scan QR yang muncul di layar
  5. Status akan berubah menjadi Terhubung

Template Pesan WA

🛒 Halaman Beli (Store Publik)

Setiap ISP mendapat halaman toko publik yang bisa dibagikan ke pelanggan untuk beli voucher hotspot secara mandiri.

URL Toko:

billing.vpntunel.my.id/beli/[slug-bisnis-anda]

Slug diatur di menu Profil. Contoh: jika slug = warnetku, maka URL toko = billing.vpntunel.my.id/beli/warnetku

Alur Pembelian Pelanggan:

  1. Pelanggan buka link toko, masukkan nomor WA
  2. Pilih server dan paket voucher yang diinginkan
  3. Bayar via QRIS (Tripay/Duitku) atau transfer
  4. Sistem otomatis kirim kode voucher ke WA pelanggan setelah pembayaran terverifikasi
Riwayat Transaksi: Semua transaksi toko publik bisa dilihat di menu Transaksi pada sidebar.

🔧 Panel Teknisi

Panel khusus teknisi lapangan untuk mengelola pelanggan PPPoE tanpa akses penuh ke sistem billing.

URL Panel Teknisi:

billing.vpntunel.my.id/teknisi/[slug-bisnis-anda]

Fitur Teknisi:

  • Lihat daftar pelanggan PPPoE (nama, username, status online)
  • Tambah pelanggan baru (otomatis push ke MikroTik)
  • Aktifkan / Suspend pelanggan dengan satu klik
  • Edit data pelanggan (nama, password, paket)
  • Hapus pelanggan (juga dihapus dari MikroTik)

Akun teknisi dikelola di menu Teknisi → Kelola Akun Teknisi di sidebar. Teknisi tidak bisa mengakses menu billing, tagihan, atau keuangan.

💰 Saldo & Topup

Saldo digunakan sebagai biaya layanan platform. Saldo diisi oleh administrator VPNTunel atas permintaan ISP.

Melihat Saldo:

  • Saldo bisa dilihat di menu Saldo atau di pojok kiri atas sidebar
  • Riwayat pengurangan dan penambahan saldo tersedia di halaman Saldo
Untuk topup saldo, hubungi administrator VPNTunel melalui WhatsApp atau Telegram yang tertera di landing page.

⚙️ Profil & Pengaturan

  • Nama ISP — nama yang tampil di sistem dan notifikasi WA
  • Username — digunakan untuk login
  • Password — ubah password login di sini
  • Nomor WA — nomor yang dihubungi admin untuk keperluan verifikasi
  • Slug Bisnis — bagian URL toko publik Anda (hanya huruf kecil, angka, dan tanda -)
Perhatian: Mengubah slug akan mengubah URL toko publik. Pastikan Anda memperbarui link yang sudah dibagikan ke pelanggan atau agen.
